# Product media

Place approved GeoNote screenshots or a demo recording here when available.

Recommended captures from a test account:

1. Reminder list with at least one location-aware reminder.
2. Create/edit reminder showing location selection and radius configuration.
3. Map view or local discovery feed.
4. Account and notification readiness (optional).

Before publishing, remove personal email addresses, profile details, precise home/work locations, live tokens, and real user content. Prefer screenshots from a dedicated demo account. Avoid store badges unless the app is actually listed in that store.

Screenshots should document the real application, not marketing mockups presented as runtime evidence.
